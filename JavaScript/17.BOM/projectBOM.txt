### ⭐ Best 10 for BOM Practice

If you want to practice the **main BOM properties and methods**, do these first:

`navigator` → Browser Info
`screen` → Screen Info
`location` → URL/Redirect
`history` → Back/Forward
`window` → Window Info
`setTimeout()` → Delayed Action
`setInterval()` → Timer
`alert()` → Alert Box
`confirm()` → Confirmation Box
`prompt()` → User Input
